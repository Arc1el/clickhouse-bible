Cloud는 콘솔의 Connect → HTTPS 주소(포트 8443)를 넣으면 됩니다. 로컬 서버 연결 시 Chrome이 "로컬 네트워크 접근" 권한을 물으면 허용을 누르세요(최초 1회). Safari는 로컬(localhost) 연결을 차단하므로 Cloud나 플레이그라운드를 사용하세요. Fiddle은 실행마다 새 인스턴스가 뜨는 공용 실험대라 CREATE/INSERT까지 가능하지만 상태가 실행 간 유지되지 않습니다 (전체 스크립트가 한 번에 실행됨). URL 끝에 #26.3처럼 붙이면 해당 버전으로 실행됩니다.
